# Frontend (Angular)

Simple Angular UI for the parking reservation API. Plain CSS, signals, hash routing, no frontend tests or mocked APIs.

```powershell
npm install
npm start        # http://localhost:4200, proxies /api and /actuator to the backend on :8080
npm run build    # production build (the Docker build does this and bundles it into Spring Boot)
```

See the root [README](../README.md) for running the backend, tests and deployment.
